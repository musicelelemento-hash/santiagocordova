# Bucle de Verificación y Calidad (SKILL7)

Esta habilidad es el escudo definitivo para tu código. Su único objetivo es que el proyecto `santiagocordova.com` esté siempre en línea y funcionando perfectamente.

## Las 6 Etapas de Seguridad

1. **Pre-Auditoría**: Análisis estático del código para detectar errores lógicos.
2. **Chequeo de Tipos**: Verificación estricta de TypeScript para evitar que datos erróneos causen errores en producción.
3. **Validación de Build**: Ejecución de `npm run build` localmente antes de cada push a GitHub.
4. **Linting de Estilo**: Limpieza automática de código para seguir los estándares más altos de Facebook y Google.
5. **Prueba de Integridad**: Verificación de que los archivos clave (como `db.ts` o `useAppStore.ts`) mantengan sus funciones intactas.
6. **Reporte Final**: Notificación detallada de cualquier problema encontrado antes de que afecte a Vercel.

## Beneficio Directo

¿Recuerdas el error de build de hace un momento? Con **SKILL7** activa, yo mismo habré detectado esa coma faltante y la habré corregido automáticamente antes de que llegara a fallar en Vercel.
