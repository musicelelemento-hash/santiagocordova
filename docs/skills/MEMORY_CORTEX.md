# CORTEX: Sistema de Memoria Evolutiva (v2)

Este archivo actúa como el "hipocampo" de la IA para el proyecto `SantiagoCordova.com`. Su objetivo es capturar patrones, preferencias del usuario e infraestructura crítica que no debe olvidarse nunca.

## 🧬 ADN del Proyecto
- **Entorno**: Windows (Local) + Vercel (Producción).
- **Stack**: Vite + React + TS + IndexedDB + Google Sheets (Sincronización).
- **Objetivo**: Gestión contable de Élite (500k) + Branding Artístico (/musica).

## 🧠 Aprendizajes Consolidados
1. **Blindaje Zod**: No permitir que datos de clientes entren al store sin pasar por `clientSchema.ts`.
2. **Prioridad Landing**: La raíz `/` SIEMPRE debe mostrar la página pública para proteger la privacidad del dashboard.
3. **Dualidad Santiago**: Mantener una separación estricta entre el Santiago Contador y el Santiago Artista.
4. **Respaldo Crítico**: La exportación JSON en Ajustes es la última línea de defensa de los 100 clientes.

## 🛠️ Reglas de Oro de Codificación (Elite)
- **Cero Placeholders**: Si falta una imagen, generarla o usar layouts premium.
- **Glassmorphism**: Usar `backdrop-blur` y bordes transparentes para mantener la estética premium.
- **Atomicidad**: Commits frecuentes con mensajes semánticos.
- **Limpieza Deslopper**: Eliminar comentarios redundantes ("// This is a function") y código muerto inmediatamente.
