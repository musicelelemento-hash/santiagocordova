# Automatización de Procesos n8n (SKILL12)

Esta es la habilidad de "Pegamento" que une todas las piezas. Permite crear flujos de trabajo que se ejecutan solos basados en lo que sucede en tu aplicación.

## Automatización de Otro Nivel

1. **Flujos Multi-App**: Cuando marcas una declaración como "Hecha", el sistema puede automáticamente:
   - Subir el archivo a Drive.
   - Enviar un mensaje de confirmación al cliente.
   - Actualizar una fila en tu hoja de administración mensual.
2. **Eficiencia Máxima**: Reduce el tiempo de tareas repetitivas a cero. Si es un proceso lógico, es automatizable con SKILL12.
